# Human mannequin

`mannequin.glb` is the CC0 **Human base mesh with editable 53-bone rig**, downloaded on 2026-10-17:

- Asset and licence: https://www.innerscene.com/tools/library/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1
- Original download: https://www.innerscene.com/api/library/human-base-mesh-with-editable-53-bone-rig-8e7c8ab1/download
- Library terms: https://www.innerscene.com/tools/library/terms

The asset derives from MakeHuman/MPFB's CC0 body and rig. It contains one neutral anatomical human mesh,
53 bones, and no textures. The original GLB is kept unchanged; the frontend straightens its supplied A-pose,
then adjusts the mesh and skeleton to 1780mm height, 800mm inseam, 500mm floor-to-knee pivot and 400mm hip-to-knee.
Body width, torso shape and cushion compression remain estimates, not measurements of Gert.
