# Campervan conversion plan

Captured from Gert's initial list on 24 October 2026. This is a working inventory, not a fixed sequence or
an approved final design. Unchecked items are pending; questions and optional work remain open.

## How this plan must work

- One person hobby project: simple, practical and easy to change.
- Break work into small, concrete actions that can be followed one by one.
- Keep instructions, costs, material sources, vendor/service/group contacts and supporting links with the work.
- Allow design, measurements, materials and task order to change as the conversion develops.
- Ultimately manage this in one or more extra tabs in the existing local web app.
- Consider editable nested TODO lists with rich notes, a grid with cost calculations, or both.
- A full spreadsheet engine is not required; fixed calculations are acceptable.
- Both Gert and the assistant must be able to update, refine and query the same information.
- No team workflows, deadlines, cash-flow forecasts or professional project-management overhead.
- First preserve this list, then research and recommend the approach before implementing the app changes.
